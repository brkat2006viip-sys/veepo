# Telegram AI Coding Agent Bot

بوت تيليجرام احترافي يعمل كوكيل برمجة ذكي (AI Coding Agent) — يقبل مشاريع ZIP، يحللها، يرسل الملفات إلى AgentRouter API، ينفذ تعليمات المستخدم، ينشئ مشاريع جديدة، يضغط النتائج ويرسل تقرير التعديلات. المشروع مبني بـ Python 3.12، قاعدة بيانات SQLite، ويدعم التخزين المشفّر لمفاتيح API لكل مستخدم.

ميزات رئيسية
- قبول مشاريع ZIP وسحب الملفات بأمان (no path traversal).
- تحليل المشروع (ملفاته، إحصاءات اللغات، عدد السطور).
- تكامل مع AgentRouter API (اختيار Provider/Model، اختبار الاتصال، رفع/تحميل النماذج).
- حفظ إعدادات كل مستخدم ومفاتيح API مشفّرة باستخدام Fernet.
- واجهة مستخدم احترافية عبر Inline Keyboard.
- تخزين عمليات/مهام التاريخية.
- حذف الملفات المؤقتة والسجلات.
- قابلية التشغيل كمجرى systemd أو Docker.

الأمان
- يتم تشفير مفاتيح API في قاعدة البيانات باستخدام Fernet.
- يتم التحقق من سلامة أرشيفات ZIP لمنع path traversal.
- يتم حذف الملفات المؤقتة بعد المعالجة.

دعم AgentRouter
- يمكنك إدخال مفتاح AgentRouter من داخل البوت (⚙️ الإعدادات -> 🔑 مفتاح API).
- يدعم اختيار provider/model وتجربة الاتصال.
- يقوم بتحميل النماذج تلقائيًا إذا كان المزود يدعمها عبر API.
